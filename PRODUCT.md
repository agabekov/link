# Личный сайт Данияра

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Личный сайт о Данияре, его увлечениях, проектах и работе. Пользователь подтвердил, что ни одна из ролей не должна становиться главным позиционированием.

## Capabilities and Constraints

- Статическая страница на HTML, CSS и JavaScript без сборки.
- Пять последних опубликованных текстов загружаются через Ghost Content API с blog.daniyar.link.
- Секция работы с историей карьеры, текущей ролью в Kaspi.kz и ссылкой «Подробнее о карьере».
- Проекты Verdict и Oneway: два столбца на компьютере, один на телефоне.
- Ссылки на Instagram и LinkedIn.
- Календарь активности GitHub для agabekov.
- Встроенный Spotify-плейлист «Spotify 2025» после календаря GitHub.
- Интеграция фотографий Instagram отложена; секции фотографий нет.

## Brand Commitments

Имя: Данияр Агабеков. Русский язык. Личная фотография daniyar.jpg. Цитата: «Если в тебе много любви, то ты вообще непобедимый».

Пользователь отверг все первые яркие макеты. Требование к новому направлению: эстетично, минималистично, красиво и аккуратно. Не использовать огромные надписи, насыщенные цветные поля и плотную плакатную композицию.

## Evidence on Hand

Текущие тексты и ссылки находятся в index.html. Центрированная светлая композиция выбрана пользователем; описание карьеры и плейлист предоставлены им. Дополнительные биографические факты не придумывать.

## Open Decisions

Основная аудитория не уточнялась; для этой версии подразумеваются люди, знакомящиеся с Данияром и его работой.
